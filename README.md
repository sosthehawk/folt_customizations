# folt_customizations

Folt erp customization

## Third-party assets

**Lexend** — `folt_customizations/public/fonts/lexend/`, served at
`/assets/folt_customizations/fonts/lexend/`. Copyright 2018 The Lexend Project Authors,
licensed under the SIL Open Font License 1.1; the licence ships alongside the font as
`OFL.txt`, which OFL §2 requires of any redistribution including binary form. The files are
Google Fonts' own pre-subset `latin` and `latin-ext` woff2 builds of the variable face, used
unmodified — deliberately, since re-subsetting would count as modification under §4.

Lexend is FoLT's brand typeface: it is what the wordmark in `public/images/folt-logo.svg` is
set in. It reaches the Desk through `folt_theme.css`.

The app's own code is MIT (see `license.txt`). OFL and MIT do not conflict; the font is
simply separately licensed.
