{#- FoLT Salary Slip — one-page A4 payslip. Built to replace the auto-generated layout, which spilled a single slip over 3-4 pages: wkhtmltopdf renders the print view at a narrow viewport, so the Desk form's bootstrap `col-xs-4` columns collapse and every label/value pair costs two full lines, and the Salary Detail child tables print all six internal columns (including `tax_on_flexible_benefit` / `tax_on_additional_salary`) squeezed side by side. Everything here is plain tables with explicit widths -- no grid classes and no flexbox -- because that is the only layout wkhtmltopdf reproduces identically to the browser preview.
